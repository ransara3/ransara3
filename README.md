## 🚀 Featured Projects

### [RISC-V CPU](https://github.com/ransara3/RISC-V-CPU)

A processor design project implemented in Verilog, exploring CPU architecture and digital system design.

### [Traffic Light System](https://github.com/ransara3/traffic-light-system)

A two-road traffic light controller implemented in SystemVerilog using a four-state Mealy finite-state machine and a hierarchical countdown timer for FPGA development.

### [UART FPGA Project](https://github.com/ransara3/UART-FPGA-Project)

A Verilog UART implementation developed for the DE0-Nano FPGA board, focusing on serial communication and hardware integration.

### [Image Processing Fundamentals](https://github.com/ransara3/image-processing-fundamentals)

Implementations of intensity transformations, histogram equalization, gamma correction, Sobel edge detection, image resampling, GrabCut segmentation, and bilateral filtering using OpenCV and NumPy.

A computer vision project for recognizing American Sign Language gestures using Python-based image processing and machine learning techniques.
